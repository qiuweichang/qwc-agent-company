# Agent Company 桌面端设计规范

## 产品气质

Agent Company 是个人使用的本地 AI 软件团队控制台。界面应像一间安静、可信、可追踪的项目作战室：信息密度高，但不使用夸张装饰；所有关键动作都能看见当前责任人、阶段和确认状态。

主视觉参考见 `agent-company-primary-screen.png`。实现以 1440px 及以上桌面浏览器为目标，不设计移动端或平板端布局。

## 布局

- 左侧项目栏：固定 220px，显示项目、四个生命周期阶段和新建项目入口。
- 中央工作区：最小宽度 760px。顶部显示项目路径与 CLI 基座，第二层是“规划线程 / 执行线程”。
- 右侧团队栏：固定 288px，展示部门经理、成员运行状态、CLI 基座和当前确认门。
- 对话区中的设计产物使用嵌入卡片；Archify 图占满卡片宽度，保留图例和图内搜索、适配、缩放控制。

## 颜色

- 页面与卡片：`#ffffff`
- 次级底色：`#f7f9fb`
- 边框：`#dde3ea`
- 主文本：`#172033`
- 次文本：`#667085`
- 品牌/进行中：`#0b8f6a`
- 品牌浅底：`#eaf8f2`
- 架构产物：`#7357d9`
- UI 产物：`#2878d1`
- 警告/等待：`#b7791f`
- 错误：`#c2414b`

不使用渐变、暗色主题和大面积彩色背景。

## 字体与尺寸

- 界面字体：`Inter, "Microsoft YaHei", "PingFang SC", sans-serif`
- 代码与路径：`JetBrains Mono, Consolas, monospace`
- 页面标题：18px / 600
- 分区标题：14px / 600
- 正文：13px / 1.65
- 辅助信息：12px / 1.5
- 圆角：小控件 7px，卡片 10px，浮层 12px

## 组件语义

- 阶段项只能有：已完成、进行中、未开始。完成态使用绿色对勾，当前态使用浅绿底和左侧强调线。
- 成员状态沿用 Runtime 的 `idle / working / stopped`，分别显示“空闲 / 工作中 / 已停止”。
- 用户确认门必须展示产物类型、版本、等待状态，并提供“确认通过”和“要求修改”两个真实动作。
- 规划线程只承载需求澄清、PRD 封板、架构/UI 方案与确认；执行线程只承载开发派单、实现、测试与验收证据。
- 不用额外连线表达辅助信息；依赖、边界、限制等放进 Archify 说明卡片。

## 交互

- Enter 发送，Shift+Enter 换行。
- 切换线程不会改变项目阶段，也不会丢失输入。
- 对未配置的外部能力显示“未配置”和所需字段，不生成伪造产物。
- 所有会推进生命周期的动作都在服务端持久化，并追加一条系统事件到对应线程。
